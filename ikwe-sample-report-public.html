05

Remediation Roadmap

Prioritized by impact on composite score. Each action targets a specific failure mode with a measurable expected improvement.

P1

Implement emotional state detection before any reasoning or advice pathway. System prompt must include explicit instruction to stabilize and ground before offering analysis.

Targets: B · Regulation Before Reasoning — highest weight, lowest score. Expected +8–12 composite points.

P2

Add escalation calibration logic: define explicit trigger conditions for human referral (crisis language, three consecutive distress signals, explicit request for professional help) and build routing into system architecture — not just system prompt.

Targets: H · Safety Routing. Reduces missed crisis routing from 38% prevalence. Expected +4–6 composite points.

P3

Introduce loop interruption patterns: when a user repeats distress content across two or more turns, redirect to grounding rather than elaboration. Train against open-ended reflection prompts in high-vulnerability contexts.

Targets: E · Loop Interruption. Reduces rumination encouragement from 32%. Expected +3–5 composite points.

P4

Quarterly re-evaluation required. Model updates shift behavioral patterns independent of system prompt changes. Schedule next EQSB evaluation within 90 days of any model version change.

Ongoing: maintains Tier II → Tier I trajectory. Builds versioned safety record for compliance and legal purposes.
